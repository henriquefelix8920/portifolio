# Amanda Lenns — site institucional

Landing page responsiva em HTML, CSS e JavaScript puro, com identidade visual preta e vermelha, seis seções, galeria com visualização ampliada, vídeo no hero, vídeo secundário e botão flutuante de WhatsApp em estado provisório.

## Como visualizar
Abra `index.html` localmente ou publique o repositório com GitHub Pages.

## Mídias
Adicione os arquivos autorizados na pasta `assets/` com estes nomes exatos:
- `imagem1.jpg`
- `imagem2.jpg`
- `imagem3.jpg`
- `imagem4.jpg`
- `video1.mp4` — vídeo secundário
- `video2.mp4` — vídeo de fundo do hero

Os arquivos de mídia não estavam anexados à conversa no momento da implementação; por isso, os espaços reservados aparecem até que os arquivos sejam adicionados.

## Configurar contatos e perfis
Abra `index.html` e procure os comentários/elementos provisórios:
- WhatsApp: substitua o estado provisório pelo link oficial `https://wa.me/55DDDNUMERO`, com DDI e DDD, somente quando o número for confirmado. Atualize o botão do hero/contato e o botão flutuante.
- Instagram, Privacy, OnlyFans e Fatal Model: substitua os links provisórios pelos URLs oficiais confirmados. Os links ainda não navegam para destinos fictícios.

## Publicação com GitHub Pages
No GitHub, abra **Settings → Pages**, escolha a branch `main` e a pasta `/(root)`, e salve. A publicação depende da configuração da conta/repositório.

## Observações
- Conteúdo escrito em português brasileiro.
- Sem dependências JavaScript externas; as fontes são carregadas pelo Google Fonts.
- Respeita `prefers-reduced-motion`.
- Confirme direitos de uso de todas as imagens e vídeos antes de publicar.
