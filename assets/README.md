# Mídias do site

Coloque nesta pasta os arquivos de imagem e vídeo autorizados:

- `imagem1.jpg`
- `imagem2.jpg`
- `imagem3.jpg`
- `imagem4.jpg`
- `video1.mp4`
- `video2.mp4`

O arquivo `video2.mp4` é o vídeo de fundo do cabeçalho principal. O `video1.mp4` é o vídeo secundário da galeria. As imagens são usadas na galeria e como pôsteres de vídeo.

As mídias originais não estavam disponíveis como anexos nesta execução; adicione os arquivos reais antes de publicar para substituir os placeholders.
